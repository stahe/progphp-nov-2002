# Introduction à la programmation WEB en PHP4

🔗 Cours original :
[https://stahe.github.io/progphp-nov-2002/](https://stahe.github.io/progphp-nov-2002/)

## Présentation

Ce dépôt contient un **support de cours consacré à la programmation Web avec PHP4**.
Il s'agit d'un document pédagogique conçu pour accompagner un enseignement et non d’un cours exhaustif.

Le document permet aux étudiants de découvrir les bases de la programmation Web en PHP et de disposer d’un support de travail pour leurs exercices et expérimentations.

## Origine du document

Ce support est directement issu du cours **« Introduction à la programmation Web en JAVA »**.
La structure pédagogique a été conservée, mais les exemples et les solutions ont été **adaptés en PHP**.

Ainsi, pour un lecteur connaissant **Java et PHP**, il devient possible de comparer :

* une solution Java
* une solution PHP

pour **un même problème de programmation Web**.

## Objectifs pédagogiques

Ce support vise à :

* Introduire les bases de la programmation Web côté serveur
* Présenter des exemples concrets de code en PHP
* Servir de base de travail pour les étudiants
* Permettre une comparaison pédagogique entre Java et PHP

## Remarques

* Ce document est **un support de cours**, pas un manuel complet.
* Certains sujets ne sont **pas abordés ou seulement introduits**.
* Des **approfondissements nécessitent l’accompagnement d’un enseignant**.

Malgré cela, les informations présentées permettent dans la plupart des cas à l’étudiant de **travailler de manière autonome**. 

## Public visé

Ce document s’adresse principalement :

* aux **étudiants découvrant la programmation Web**
* aux personnes souhaitant **comparer les approches Java et PHP**
* aux apprenants utilisant PHP dans un cadre pédagogique
